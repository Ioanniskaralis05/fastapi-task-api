# FastAPI Task API

A professional REST API Task Manager built with FastAPI and SQLite.

## Features

- Create tasks
- View all tasks
- Update tasks
- Delete tasks
- SQLite database integration
- RESTful API endpoints
- Interactive API documentation with Swagger UI

## Technologies Used

- Python
- FastAPI
- SQLite
- SQL
- Uvicorn
- Git
- GitHub
- Docker

## API Endpoints

- GET /tasks
- POST /tasks
- PUT /tasks/{task_id}
- DELETE /tasks/{task_id}

## How to Run

```bash
python -m uvicorn app:app --reload
